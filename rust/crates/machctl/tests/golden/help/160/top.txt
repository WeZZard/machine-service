usage: machctl [-h] [--environment ENVIRONMENT]
               {environment,acquire,wait,list,images,images-show,status,exec,push,pull,heartbeat,release,capabilities,acquisition-capabilities,console-resolve,console-open,console-cancel,gc} ...

client for machine-service (leases of Tart VMs and durable Macs)

positional arguments:
  {environment,acquire,wait,list,images,images-show,status,exec,push,pull,heartbeat,release,capabilities,acquisition-capabilities,console-resolve,console-open,console-cancel,gc}
    environment         resolve environment offline without writing files
    acquire             lease a machine: a fresh VM clone, or a durable Mac
    wait                block until a lease is running (useful after --no-wait)
    list                list every machine from every instance
    images              query every instance's images and capacity
    images-show         show one image's full record on every instance (JSON)
    status              show one lease
    exec                run a command in the guest
    push                copy host -> guest
    pull                copy guest -> host
    heartbeat           reset TTL; keeps a leased machine alive
    release             end a lease; a VM is stopped, deleted and unregistered
    capabilities        show every instance's supported and unavailable network capabilities
    acquisition-capabilities
                        describe every instance's acquisition and console prerequisites without allocating a VM
    console-resolve     resolve the exact lease console; viewer is on the service host
    console-open        open the exact lease console; viewer is on the service host
    console-cancel      cancel the exact lease console; viewer is on the service host
    gc                  run TTL reclaim now

options:
  -h, --help            show this help message and exit
  --environment ENVIRONMENT
                        absolute selected-environment profile path
